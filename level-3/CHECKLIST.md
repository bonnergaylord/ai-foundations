# Level 3 work

What Level 3 adds to this folder, and which module asks for each:

- Your database load scripts and the code for your connection, Modules 3.1 and 3.2.
- `README.md`, Module 3.3. What the project does, how to run it, and where it is
  deployed. You write this file. It is not in the kit.
- `commercial-use-note.md`, Module 3.3. What would make this commercial rather than
  coursework. You write this file too.

Never commit an API key, a password, or a connection string. If you are unsure whether
something is a secret, ask before you push.
