# AI Foundations, portfolio repository

This folder becomes your repository in Module 2.2. Your name goes on the commits, the
history is dated, and nothing in it expires when the program ends.

Follow the commands in Module 2.2 exactly. This file does not repeat them, so there is
one set of instructions to follow rather than two.

## What is in the kit

| Item | What it is for |
| --- | --- |
| `notes.md` | A short notes file. Module 2.2 has you edit one line of it on two branches to practise resolving a conflict. |
| `level-1/` | Move the work you already produced in Level 1 into this folder before your first commit. `level-1/README.md` lists it. |
| `level-2/` | `compare.md` is the template for Module 2.3. `CHECKLIST.md` lists what Level 2 adds here. |
| `level-3/` | `CHECKLIST.md` lists what Level 3 adds here. You write the `README.md` and `commercial-use-note.md` yourself in Module 3.3. |
| `.gitignore` | Tells Git which files never to record, such as `.env` files that hold secrets. Leave it in place. |

Keep the repository **public** when you submit. The automatic checks read it through
GitHub, and so will an employer.

## After the program

Add to it. When you learn something in an internship, it goes here too. The credential is
a moment. This repository is the part that compounds.
